# Rafi's Portfolio Website

This is a beginner-friendly, responsive portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year
- `assets/` — put your CV and optional images here

## Before publishing: personalize these details
1. Replace `your.email@example.com` with your real professional email.
2. Update LinkedIn and GitHub links with your actual profile URLs.
3. Put your CV PDF at `assets/cv.pdf` (keep that exact filename or update the links in `index.html`).
4. Replace the emoji/photo placeholder in the hero with your professional photo if desired.
5. Rewrite the About, Skills, and Projects sections to include only accurate skills and real work.
6. Update the project descriptions with real projects. Do not claim experience you do not have.

## Preview locally
- Open `index.html` in your browser, or
- Open the folder in Visual Studio Code and use the Live Server extension.

## Publish with GitHub + Vercel
1. Create a GitHub account at https://github.com/
2. Create a new public repository, e.g. `rafi-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Sign in at https://vercel.com/ using GitHub.
5. Choose **Add New → Project**, import `rafi-portfolio`, and deploy.
6. Vercel will provide a public URL. Open it and test the site on both phone and computer.

No build command or framework is required for this static website.
